# ツボ単

経穴を「見て覚える」ための3D図鑑アプリ。手の太陰肺経11穴・足の少陰腎経27穴・手の厥陰心包経9穴・足の太陽膀胱経67穴（左右とも）を収録した試作版。仕様は [CLAUDE.md](./CLAUDE.md)。

## 使い方

公開版：https://ys07302004-lab.github.io/tsubotan/ （main に push すると GitHub Actions で自動公開。配置モードは末尾に `?dev`）

```bash
npm install
npm run dev        # http://localhost:5173 （スマホで見るときは同じLANから表示されたNetworkのURL）
npm run build      # dist/ に出力（PWA）
npm run preview    # ビルド結果の確認
```

- **3D**：1本指ドラッグで回転、ピンチで拡大、2本指ドラッグで移動。点をタップすると詳細カード（その穴を正面から見る向きにカメラが動く）
- **視点ボタン**（右上）：前・横・後・全体
- **詳細カード**：横スワイプか ‹ › で前後の穴へ。▾ で見出しだけに畳む
- 走行線と物差しは皮膚の表面に沿わせて描く。体の向こう側にある点・線は薄く表示する
- **一覧**：タップするとその穴へカメラが寄る
- **皮膚スライダー**：0〜100%。下げると骨が透ける
- **骨・筋・動脈・神経**：スライダーの下のボタンで表示を切り替える（筋・動脈・神経はオンにしたときに読み込む。オンにすると皮膚を30%に下げる）
- **配置**（開発用）：開発サーバー、または URL に `?dev` を付けたときだけ出る（下記）

## 3Dモデル

[BodyParts3D](https://dbarchive.biosciencedbc.jp/en/bodyparts3d/) 4.0（part_of 版、解像度 99）から作成。

| ファイル | 中身 | 元データ | 頂点 / 三角形 | サイズ |
|---|---|---|---|---|
| `public/models/skin.glb` | 皮膚（外側の面だけ）。頂点色で手掌・足底（赤白肉際の白い側）と爪を塗り分け | FMA7163 skin（FJ2810） | 54,949 / 109,183 | 0.26 MB |
| `public/models/bones.glb` | 全身の骨＋肋軟骨（1メッシュに結合） | is_a ツリーの FMA5018 bone organ と FMA7591 costal cartilage の下にある 213 パーツ | 287,126 / 520,284 | 1.27 MB |
| `public/models/muscles.glb` | 上肢・下肢の筋（重心が手足にある部品） | is_a ツリーの FMA5022 muscle organ | 231,982頂点 / 142部品 | 0.95 MB |
| `public/models/arteries.glb` | 上肢・下肢の動脈（同上） | FMA50720 artery | 139,626頂点 / 102部品 | 0.58 MB |
| `public/models/nerves.glb` | 神経（BodyParts3D に入っている主な神経すべて） | FMA65132 nerve | 16,555頂点 / 26部品 | 0.09 MB |

- Draco 圧縮済み（位置 14bit 量子化：全身でおよそ 0.1mm 単位なので取穴の精度には影響しない）。ポリゴン削減はしていない
- part_of ツリーの「skeleton」には上肢・下肢の骨が入っていないため、骨は is_a ツリーから集めている
- 皮膚の OBJ は厚みのある殻で、外側の面と約2mm内側の面の2枚が入っている。内側の面があると表面に寄せた点が皮膚の下に入るので、変換時に外側の面だけを残している
- デコーダは `public/draco/` に同梱（オフラインでも動くように CDN を使わない）

### 作り直す手順

```bash
npm run model:download            # bp3d/ に OBJ と部品リストを取得（is_a 版 zip を含め約550MB、git には入れない）
python3 scripts/skin_regions.py   # 皮膚の頂点を「皮膚・手掌足底・爪」に分ける → scripts/skin-regions.txt
npm run model:convert             # public/models/*.glb を生成（--no-draco で非圧縮）
```

- 手掌・足底：手足の皮膚のうち法線が掌側・足底側を向く所。境目がおおよその赤白肉際になる
- 爪：末節骨の背側（手指は手背、母指は外側、足指は上）で、骨の長さの3割〜先端の手前まで

### 座標系（実測で確認）

| | 単位 | 上方向 | 体の前 | 体の右 |
|---|---|---|---|---|
| BodyParts3D の OBJ | **mm**（OBJ ヘッダの `Bounds(mm)` と、皮膚の高さ 1719.5mm で確認） | **+Z** | **-Y**（鎖骨・足先が -Y 側） | **-X**（肝臓・右鎖骨が -X 側） |
| アプリ（three.js） | **m** | **+Y** | **+Z** | **-X** |

変換は `(x, y, z)_mm → (x, z, -y) × 0.001`（X軸まわりに -90° 回転してから mm→m）。原点は BodyParts3D のまま動かしていない（足底がおよそ y = -0.078 m、頭頂が y = 1.641 m）。
正面のカメラ（+Z 側）から見ると、体の右は画面の左に来る。
後でクイズ側と合体するときは、この表をクイズ側と突き合わせ、ずれがあれば `scripts/convert-bp3d.mjs` の変換1か所で合わせる。

モデルの姿勢は解剖学的正位（手掌が前を向き、母指が外側）。

## データ

| ファイル | 中身 |
|---|---|
| `data/lung.json` / `data/kidney.json` | 肺経11穴・腎経27穴。形式は CLAUDE.md の通り（`positions` に左右の位置） |
| `data/kotsudo.json` | 骨度法の区間 |
| `data/landmarks.json` | 骨度法の物差しの端になる基準点（`kotsudo.json` の `from` / `to` と同じ名前、`side` は R / L / midline）の3D座標 |

- `position` はアプリ座標（m）。`positionStatus` が `checked` でない穴は、カードに「3D上の位置は仮置きです」と出る
- 骨度法の物差しは `from` の点から `to` の点までの直線を `sun` 等分し、`extend` があれば同じ目盛りで `to` の先へ延長（点線）する。目盛りの位置は皮膚の上に寄せて描く（`src/surface.ts` の `path`）
- 仮置きの位置は、骨度法で寸数が決まる穴（LU1・LU3・LU4・LU6〜LU8）は物差しの目盛り（同じ計算）の上に置いている。鎖骨中線は鎖骨の中点を通る線として取った（このモデルで1寸≒19.5mm）

### 仮置きの位置の決め方

`scripts/derive/` が、教科書『新版 経絡経穴概論 第2版』（医道の日本社）の部位・取り方・骨度（表1-2）に合わせて、BodyParts3D の骨・筋・腱・動脈の位置から計算して皮膚の上に置く。教科書の本文や画像はリポジトリに入れていない。

```bash
node --experimental-strip-types scripts/derive/main.ts          # 全経絡
node --experimental-strip-types scripts/derive/main.ts BL       # 膀胱経だけ
```

- `positionStatus: "checked"` の穴・基準点は上書きしない。計算した位置はすべて `draft`
- 右側で計算し、左は x を反転して皮膚へ寄せる（モデルはほぼ左右対称）
- 寸で決まる穴は、アプリの物差し（`SkinSurface.ruler`：2点を通る平面で皮膚を切った線の道のりを等分）と同じ計算で置く
- 赤白肉際は皮膚の塗り分け（手掌・足底）の境目、爪の角は爪の塗り分けから求める
- このモデルでの1寸：胸腹部の横（両乳頭間8寸）≒27mm、臍〜恥骨結合上縁≒30mm、胸骨体下端〜臍≒28mm、上腕（腋窩横紋前端〜肘窩）≒23mm、前腕≒19mm、下腿（内果尖〜膝窩1尺5寸）≒25mm、背部の横（肩甲棘内端縁間6寸）≒19mm、頭（眉間〜大椎1尺8寸）≒27mm、頭の横（両乳様突起間9寸）≒13mm

モデルに無いものを推定している所（教科書で特に確かめてほしい所）：
- 前髪際・後髪際（髪が無い）：眉間〜大椎を1尺8寸とし、前髪際＝眉間の上3寸、後髪際＝大椎の上3寸
- 尾骨（部品が無い）：仙骨の下端から2.5cm下を尾骨下端とした（会陽）
- 後仙骨孔（八髎）：上髎＝上後腸骨棘の頂点の高さ、次髎＝上後腸骨棘の下縁の高さ、中髎・下髎は同じ間隔で下。左右の位置は下へ行くほど正中へ寄せた
- 中府・雲門：このモデルは乳頭が外寄りで、乳頭線で測った6寸が烏口突起より外になる。位置は取り方（雲門：鎖骨中央のやや外方下際）を優先しているので、物差しの6寸とは一致しない

### 配置モード（開発用）

1. 右上の「配置」を押す（本番ビルドでは URL に `?dev` を付ける）
2. 対象（経穴または基準点）を選び、皮膚をタップする。当たり判定は皮膚だけで、透明度0%でも骨の上には置かれない
3. 位置は 0.1mm 単位に丸めてブラウザに一時保存される。「置いたら次へ」をオンにすると次の対象へ進む
4. 教科書で確認できたら「教科書で確認済み」にチェックを入れる
5. 「JSONを書き出す」で `lung.json` と `landmarks.json` をコピーまたは保存し、`data/` に上書きする
